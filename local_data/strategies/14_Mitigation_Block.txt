NAME: Mitigation_Block
DESCRIPTION: Continuation entry on the retest of an order block that holds (no body close through its extreme)
SYMBOL_DEFAULT: XAUUSD
TIMEFRAMES: 4h, 1h (identification), 15m, 5m (entry)
MITIGATION_DEFINITION:
- Start with a valid order block as defined in OB_Continuation.
- The retest of that order block is classified as a mitigation event only if no candle's body (close price) trades beyond the order block's far extreme; a wick through the extreme is permitted, a body close through it is not.
- If a body close beyond the extreme does occur, reclassify this setup as Breaker_Block_Reversal instead; do not apply this file's rules to that scenario.
ENTRY_CONFIRMATION: [OPTIONS]
- wick_reject: price retests the order block, wicks into it if at all, and prints a rejection candle closing back in the original trend direction — the primary trigger, matching the "block holds" nature of a mitigation
- close_beyond: a lower-timeframe (5m) candle closes beyond its own most recent minor swing point while inside the order block — a stronger-confirmation alternative
STOP_LOSS: [OPTIONS]
- swing_based: stop placed beyond the order block's far extreme (wick, not body) — the primary stop, since a body close through it reclassifies the setup as Breaker_Block_Reversal
- fixed_atr: stop placed 1.5x ATR(14) beyond the order block's far extreme — use when the order block is unusually small
(all modes: clamp to broker/data minimum stop distance if too tight)
TAKE_PROFIT: [OPTIONS]
- fixed_2R: full close at a fixed 2R — the base case
- partial_1_5R: partial close at 1.5R, remainder to breakeven and trailed toward the next break-of-structure level in the original trend direction — the standard choice
FILTERS:
- Skip entry if a body close beyond the order block's extreme has occurred (redirect to Breaker_Block_Reversal instead)
- Skip entry if this specific order block has already been retested and mitigated once before — older, previously-touched blocks are lower quality for a second entry
NOTES:
- Same underlying mechanic as OB_Continuation, described from the retest side. Mirror case of Breaker_Block_Reversal.
