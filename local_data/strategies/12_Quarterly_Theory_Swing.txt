NAME: Quarterly_Theory_Swing
DESCRIPTION: Long-horizon swing bias derived from a calendar-quarter accumulation-manipulation-distribution cycle
SYMBOL_DEFAULT: XAUUSD
TIMEFRAMES: 1M, 1W (quarter placement), 1d (true-open tracking and phase read), 4h, 1h (entry)
TRUE_OPENS:
- Yearly true open: the opening price of the first Monday of April.
- Monthly true open: the opening price of the second Monday of the month.
- Daily true open: the opening price at 20:00 CET / 14:00 EST, consistent with the true-day definition used elsewhere in this rulebook.
- Use these true opens as reference anchors when determining whether price is in an accumulation, manipulation, or distribution phase relative to the current quarter.
ENTRY_CONFIRMATION: [OPTIONS]
- close_beyond: once distribution is confirmed (a break of structure away from the manipulation-phase sweep, per the TRUE_OPENS phase read), a 4h/1h candle closes beyond its own most recent minor swing point in the distribution direction — hardcoded generic trigger, since the parser cannot reference OB_Continuation or Liq_Sweep_Reversal's rules at runtime
- wick_reject: as an alternative, price retests the order block formed at the start of distribution, wicking into it and closing back out in the distribution direction
STOP_LOSS: [OPTIONS]
- swing_based: stop placed beyond the swing point or order block extreme that defines the start of the confirmed distribution phase — hardcoded generic rule
- fixed_atr: stop placed 1.5x ATR(14) beyond that same reference point
TAKE_PROFIT: [OPTIONS]
- trail_only: no fixed target given the multi-week holding horizon; trail behind new weekly/daily swing points once the position is in the confirmed distribution phase — the primary choice
- fixed_2R: full close at a fixed 2R if a smaller, defined target is preferred over trailing (note: 2R is a modest target relative to this strategy's typical multi-week horizon — trail_only better matches the intended holding period)
FILTERS:
- Require an intraday confirmation entry (per ENTRY_CONFIRMATION) before opening a position — a quarterly bias read alone, without a confirmed structural entry trigger, is not sufficient to open a trade
- Limit position review and re-evaluation to once per quarter, to avoid fitting the calendar to price action after the fact
NOTES:
- This is the file in this rulebook most reliant on a fixed-calendar narrative rather than directly observable price mechanics. Treat entries generated by this file with more skepticism and smaller position size than the order-flow-based files until independently backtested.
- Parser compatibility: this file previously referenced OB_Continuation and Liq_Sweep_Reversal by name ("inherit_ob_continuation" / "inherit_liq_sweep_reversal" / "inherit_from_underlying_strategy") for its entry and stop-loss logic. The parser cannot resolve cross-file references, so a hardcoded, self-contained version is used above. Update this file by hand if those two files' rules change.
